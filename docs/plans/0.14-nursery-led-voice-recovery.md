## Frozen music feature transport (UI + Platform)

Retain adapter envelope v=1 and cmd=visualizer, args.action=frame, owner and existing 24-hex-character levels. Add args.feature_version=2 and flat numeric fields:

- seq: unsigned 32-bit monotonic sequence per producer session; timestamp_ms: monotonic milliseconds.
- session: unsigned 32-bit nonzero producer session identity; reset is accepted only on new ownership/start or expired old stream, never by every frame.
- energy, warmth, brightness_axis, density, transientness, groove, build, spaciousness, loudness_fast, loudness_slow, onset_low, onset_mid, onset_high, beat_strength, beat_confidence, novelty, event_strength: integers 0..255.
- beat_phase: 0..65535; bpm_x100: 0..30000; events bitmask: kick=1, snare=2, high=4, fill=8, build=16, reentry=32, breakdown=64, section=128, drop=256.
- Existing args.brightness retains LED master meaning; do not confuse it with brightness_axis.

Reject malformed, stale, reordered or duplicate v2 frames without mutating accepted scene state. Bounded timestamp discontinuity resets must be explicit. Legacy packets without feature_version remain valid compatibility spectrum frames. Producer transport stays nonblocking/best effort; no LED outage may block audio. No claim of semantic instrument recognition.

## Task 2: Idle and sleep LED base layers (#110, #101)

Change all idle restoration sites to a single base renderer. Default idle off; persist explicit off/indicator/always modes, with optional very dim single front pixel and existing always-on colour. Document dark idle is healthy, and night mode caps rather than selects the base owner.

Add sleep_light daemon command/status: mode off/solid/pulse, brightness 0..20 percent, period_ms 3000..15000, timer_minutes 0..720. Reject invalid inputs server-side, do not clamp malformed requests silently. Persist selected settings but start off unless explicit restore_on_boot=true; boot diagnostics remain higher priority. Use a monotonic absolute pulse phase so pre-emption does not restart the waveform. Timer expiry selects off. Privacy, error, setup/recovery, wake/listening/thinking, tests and transient owners pre-empt the base immediately. All frames traverse Task 1. Tests cover idle default/restoration, persistence, safe bounds, pulse continuity, expiry and each priority class.

## Task 3: Director and musical transitions (#64, #65)

Create portable protocol/director/render units with deterministic session-seeded state. Implement Ribbon, Twin Arcs, Orbit, Split Pulse, Classic Mirror and Ember through one twelve-pixel interface. Hold scenes >=10 seconds absent explicit reset, crossfade around 1 second, restrained two-colour palettes and visible negative space. Low beat confidence must not force a phase-locked orbit. Keep v1 classic compatibility.

Remove timer-triggered major comets. Implement inhale/cut/bloom, aperture, knife sweep and sparse shock transitions as bounded state machines. Require structural flags plus confidence/novelty/history, cooldown >=8 seconds, at most two near-white accent pixels and 100..300 ms high-contrast segments. Higher-priority ownership aborts the transition; resume the scene without replaying old events. Tests replay deterministic steady, sparse, build/drop, quiet/reentry, isolated-hit, reordered-frame and interruption traces; assert dwell, geometry, duration, cooldown and output budgets.

Platform counterpart extends existing audio_visualizer with bounded history, differentiated onset bands, slow axes, beat confidence/phase, structural estimates and the frozen v2 producer; retain v1 operation. Add real producer-to-consumer fixture validation. Hardware profiling and subjective tuning remain separate.

## Task 4: USB Opus (#118)

Create radio_opus.[ch], use confined already-open USB file descriptors and Ogg/Opus identification; do not treat all Ogg files as Opus. Decode via pinned libopusfile/libopus/libogg to signed stereo 48 kHz and existing media bus; handle preskip, gain, EOF, malformed/truncated streams, mono/stereo and chained links within bounds. Preserve cancellation and avoid reopening arbitrary paths. Provide static dependency build provenance and notices, integrate Platform build hook. Capability-unavailable builds must reject Opus honestly rather than show false playable success. Tests decode real generated finite Ogg Opus fixtures and negatives, check actual nonzero PCM/length and cancellation. Measure binary increase where toolchain exists; full image headroom is explicitly unverified without a candidate build.

Serialized API/UI pass accepts .opus case-insensitively alongside .mp3 only when decoder is available, updates play affordances and messages, and tests unsupported extensions and malformed files.

## Task 6: Private recent voice history (#102)

Extend canonical agentd history, not log scraping or a parallel transcript listener. Exactly ten completed/failed/cancelled records newest first; stable IDs/timestamps, bounded transcript/response/status/timings. Cover STT failures before a transcript, assistant failures, TTS failures, cancellation and timeout once per canonical turn. Do not silently truncate client input. Expose only human-facing final text, no credentials, raw tool payloads or hidden prompts. GET existing /assistant/history and DELETE same path, preserve existing POST clear alias; auth/CSRF unchanged. UI newest-first scroll panel + clear with stale-response generation guards. Tests rollover 11→10, escaped expansion, oversize internal text, every terminal status, immediate clearing, no persistence, and authentication.

## Task 7: Secure recovery connectivity (#96)

Implement networkd recovery lifecycle and a Platform-owned executable helper/early-boot action-button detector. Physical long-hold (~5 seconds) writes a strict root-owned tmpfs marker; never arm dev escapes or alter partitions. Automatic fallback defaults off and requires explicit owner opt-in; physical recovery enabled by default, timeout default 120 seconds with bounded configuration.

Use capability checks for packaged hostapd/DHCP/DNS and AP driver support. Fail closed with actionable unavailable reason; never claim AP active from a marker alone. Use a randomly generated per-device WPA2 secret stored mode 0600, not a publicly predictable serial-derived password. Never log or export it. Recovery mode does NOT bypass existing account authentication/CSRF or reopen account creation/factory reset. Captive setup UI must guide an existing owner through login and Wi-Fi-only reprovisioning, preserving accounts/configuration. Credential attempts are rate-limited. Track exact helper/child ownership, bounded startup/teardown and cleanup. Invalid STA credentials restore/retain AP with visible error; successful association tears AP services down and returns normal LED ownership. No real host networking, radio changes or reboot during tests.

Respect the existing WMT one-transition policy; keep radio power controls unchanged. If AP cannot work on supported hardware, expose the actual blocker, not a simulated success. Platform packaging must pin sources/licenses and carry required helper binaries. Host fixtures exercise real helper functions with isolated command oracles and button evdev input, success/failure/timeouts, malicious markers, process cleanup, auto opt-in and no credential leakage. BLE provisioning is explicitly phase two and excluded by issue comments.
